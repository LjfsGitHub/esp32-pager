# v0.1.0 — 首次公开发布

**ESP32 Pager**：开源 ESP32-S3 AMOLED 手表 + Windows PC Bridge，MIT 许可证。

## 亮点

- **双硬件分支**
  - `main`：Waveshare [ESP32-S3-Touch-AMOLED-2.16](https://www.waveshare.com/esp32-s3-touch-amoled-2.16.htm)（480×480 方屏）
  - `round-amoled-1_75c`：ESP32-S3-Touch-AMOLED-1.75C（466×466 圆屏 + AXP2101 补丁）
- **手表端**：Wi-Fi 配网、6 位配对、TLS WSS、PTT 语音、L0–L3 审批、主机 CPU/GPU 环、LVGL / Brookesia 三页 UI
- **PC Bridge**：`127.0.0.1:8765` Web Agent Center；ACP 多智能体（Hermes / Cursor / Codex / Claude / WorkBuddy）
- **隐私**：默认空 `devices.json`，打包脚本剔除聊天/会议/审计日志

## 快速开始

```powershell
git clone https://github.com/LjfsGitHub/esp32-pager.git
cd esp32-pager\bridge
pip install -e .
python -m pager_bridge.serve
```

固件：ESP-IDF 5.5.x → `examples/esp-idf/03_esp-brookesia` → 按分支烧录。
