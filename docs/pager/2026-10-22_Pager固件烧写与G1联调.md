## 本轮代码变更

- 设备端审批页补上触摸按钮：`批准` / `拒绝`。
- L3 审批页显示禁用的 `回电脑批准`，`拒绝` 始终可用。
- 固件层在 `pager_net.c` 增加拦截：设备发起的 L3 `allow` 直接拒绝。
- Bridge 的 `resolve_approval()` 增加 `remote` 来源参数：
  - 设备 WSS 调用 `remote=True`，L3 allow 返回失败。
  - PC 管理 API/WS 默认 `remote=False`，允许在电脑批准 L3。
- `can_approve_remotely()` 对任何 L3 返回 `False`。
- PC UI 增加待审批操作条：`批准` / `拒绝`；L3 显示“在电脑批准”。
- PC UI 的 L3 预览 fixture 改为 `canApprove:false`，文案为“需要回电脑确认”。
