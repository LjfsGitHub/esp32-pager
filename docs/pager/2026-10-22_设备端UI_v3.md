# 设备端 UI v3（2026-10-22）

## 目标

把 1.83 英寸 240×284 设备屏从“能用”提升到和 Web 端一致的视觉语言：深石墨底、橙色强调、圆角卡片、清晰层级、底部 PTT dock。

![设备端 UI v3 布局预览](assets/pager_ui_v3_preview.png)

> 上图是 240×284 的 1:1 布局预览（2× 展示）。浏览器字体为回退字体，设备上用 HarmonyOS Sans SC。

## 已实现

- **字体**
  - 正文改为 HarmonyOS Sans SC 16px，完整 GB2312。
  - 标题新增 HarmonyOS Sans SC Bold 24px 子集（273 个字形，含动态审批动作补字），缺字回退 16px。
  - 数字/英文使用 Montserrat（配对码 40px；品牌 16px；顶部状态 24px）。
- **主页**
  - 顶部状态栏：橙色品牌点、`PAGER` 字标、当前状态、WiFi/电池；审批时切换为 `L2/L3` 风险 pill。
  - 中央 104px 呼吸环 + 88px 表情，按空闲/思考/执行/审批/错误切换颜色。
  - 24px 大标题 + 16px 副标题 + 14px 细节，取代原来的单行小字。
  - 结果卡：`RESULT` 标签 + 可滚动正文。
  - 页码点和底部 216×38 PTT dock（24px 标签）；支持**按住屏幕 dock 说话**，也保留侧键 PTT。
- **审批页**
  - 220×176 风险卡：左侧色条、`L2/L3` 徽标、风险说明、24px 操作名、目标行、操作提示和 `LOCAL APPROVAL` 页脚。
  - 底部 102×40 操作按钮更靠近屏幕下沿；审批页隐藏页码点，避免和按钮抢视觉。
  - L2：橙色“批准”+ 深红“拒绝”。
  - L3：批准按钮禁用为“回电脑批准”，仅保留拒绝；设备端仍然不能批准 L3。
  - 审批后显示 `OK/NO` 结果态，再回到主页。
- **设置/配对/配网/WiFi**
  - 设置页改为卡片行：自动播报、音量、重新配网、重新配对、返回。
  - 配对页：40px 大字码、3×4 圆角键盘、确定键橙色。
  - 配网页：AP 名称卡片、`192.168.4.1` 大字、2.4GHz 提示。
- **交互保护**
  - 按住 PTT 时禁用左右滑动，避免录音中误切页。
  - 结果卡显示时开始新一轮 PTT 会先隐藏旧结果。

## 构建与烧录

```powershell
cmd /c "set IDF_TOOLS_PATH=C:\Users\Administrator\.espressif&& call D:\ESP32\.tools\esp-idf-v5.3.2\export.bat && idf.py build"
cmd /c "set IDF_TOOLS_PATH=C:\Users\Administrator\.espressif&& call D:\ESP32\.tools\esp-idf-v5.3.2\export.bat && idf.py -p COM6 app-flash"
```

- 构建通过。
- `pager.bin` 大小 `0x1F98F0`，app 分区剩余约 78%。
- 已烧录 COM6，启动日志正常，WiFi 连接 `1102`，bridge WebSocket 已连上（`connected: 1`）。
